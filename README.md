## 我的 AI Coding 方法

```text
先定义边界       -> 输入、输出、失败状态、不可变约束
让模型做加速器   -> 候选实现、测试、迁移草案、排障假设
人负责工程判断   -> 设计、权限、兼容影响、真实业务语义
用证据收敛结果   -> 测试、日志、复现、Diff 审阅、小 PR
```

我会把模型输出落到类型、测试、日志和文档中，让“会写代码”变成“能交付、能维护”。
